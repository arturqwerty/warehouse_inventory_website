# УПП_24.25.1

## Project Goal
Система учёта работы склада для кладовщиков и руководителей, позволяющая оформлять приход, расход и инвентаризацию товаров, контролировать остатки и предотвращать недостачи.

## Инструкция по запуску
1. Открыть терминал (Git Bash или PowerShell) и склонировать репозиторий:
git clone https://github.com/arturqwerty/УПП_24.25_1.git
cd УПП_24.25_1

2. Установить зависимости:
npm install

3. Запустить dev-сервер:
npm run dev

4. Открыть в браузере:
http://localhost:3000
